## 全体と問題の種類ごとの集計

$metrics

入力トークンはキャッシュ作成・読取を含む。時間は探索開始から結果の読込み・根拠確認までの壁時計で測り、採点時間・採点トークンは含めない。
根拠がない場合の未確認割合は None（値なし）。結果を取得できない問題も不正答として分母に含める。

## 採用判定

$adoption

正答率は基準方式の 9 割以上、対象方式の未確認根拠は総根拠数の 1 割以下。根拠が 0 件なら不採用。
