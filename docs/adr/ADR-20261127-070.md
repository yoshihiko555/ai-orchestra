# ADR-20261127-070: 実 API 評価の結果に基づくリポジトリ探索エージェントの採用

- **ステータス**: accepted
- **日付**: 2026-11-27
- **決定者**: manager（評価結果と L-01 の採点を確認。人の最終確認は PR で行う予定）

## コンテキスト

[ADR-20261127-069](./ADR-20261127-069.md) で定めたリポジトリ把握の20問評価を、manager が人の了承を得て実 API で実行した。
ソースは `0fcd20d`、対象は `eval-reader`（gemini / gemini-4-neon）である。
結果と実行条件は [2026-11-27 の評価報告書](../evaluation/repo-understanding/report-2026-11-27.md) に記録した。

baseline は 20/20 正解、agent は 19/20 正解だった。未確認の根拠は baseline が 92 件中 11 件、agent が 105 件中 0 件だった。
唯一の不正解である agent の L-01 は、場所の特定は正しかったが `--profile=` を使う条件の説明が欠けており、manager は採点を妥当と確認した。

## 検討した選択肢

### 選択肢 A: 評価結果に基づき採用する

- メリット: 正答率 `0.95 ≥ 1.0 × 0.9` と未確認割合 `0.0 ≤ 0.1` の両条件を満たす。manager による不正解の採点確認もある。
- デメリット: 試行は 1 回で、根拠の意味的な正しさや他のリポジトリでの性能を保証する結果ではない。

### 選択肢 B: 採用を保留する

- メリット: 追加の比較や確認を待ってから判断できる。
- デメリット: 今回の評価は既定の採用条件を満たしており、この結果に基づく判断を残せない。

## 決定

選択肢 A を採用し、`eval-reader`（gemini-4-neon）による `orchex llm agent` のリポジトリ探索を採用する。
正答率と未確認割合の両条件を満たし、manager が L-01 の採点を妥当と確認したことを根拠とする。
人の最終確認は PR で行う予定であり、実施済みとは扱わない。

## 影響

この判断は今回の20問・1回の評価に基づく。baseline の根拠照合は Read の記録だけを使う近似で、パス単位の除外も強制していない。
採点は Claude が行い、`verified` は主張の意味的な正しさまでは保証しない。
baseline の未確認割合約 12% と agent の 0% の差を、そのままでっち上げの多さの差と解釈しない。
回答と採点理由を報告書から参照できる形で保存し、人の最終確認に使う。
既存の認証・プロファイル・ルーティング設定と ADR-20261127-069 の契約は維持する。
