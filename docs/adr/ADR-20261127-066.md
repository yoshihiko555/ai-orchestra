# ADR-20261127-066: Antigravity CLI の連携を廃止する

- ステータス: 採用（accepted）
- 決定日: 2026-11-27
- 範囲: T1（CLI の削除）。API 共通基盤は後続タスク T2 で扱う。

## 背景

Google の利用規約上の理由で Antigravity CLI（`agy`）を利用できなくなった。
ADR-20260612-024 の CLI 連携を廃止する。
ADR-20260717-042 の proposer への routing config patch（`antigravity.model`）の解放と、ADR-20261028-060 の任意助言は、
Antigravity に関係する部分だけを置き換える。Codex に関する決定は維持する。

## 決定

- 専用パッケージ、ルーティング、コマンド生成、提案、監査検出、モデル設定を削除する。
- researcher は `claude-direct` とし、Read / Grep / Glob / WebSearch / WebFetch で調査する。
- ux-reviewer と reverse の解析も Claude 自身で実行する。auto の候補は Codex と直接実行だけとする。
- meta-harness の config_patch の上限から `antigravity.model` を、許可する tool 値から `antigravity` を外す。
- 旧 `antigravity:` / `gemini:` 節は値を利用せず、削除を促す警告を出す。
  旧 `tool: antigravity` / `tool: gemini` は `claude-direct` として扱い、対象キーの移行を案内する。
- `antigravity-suggestions` / `gemini-suggestions` が導入一覧に残っていても、sync と他パッケージの install を継続できるようにする。
  sync で導入一覧・ハッシュ台帳・hook 登録を整理し、利用者の local 設定と無関係な hook は保持する。
- Codex の設定解決、sandbox、安全条件、委譲手順は変更しない。

## 結果

既存導入先は同期後も調査とルーティングを継続できるが、agy による調査とマルチモーダル処理は利用できなくなる。
互換処理は旧設定を受け付けるためだけに残し、旧 CLI の実行経路は残さない。
`orchex llm` / `orchex auth`、`api:` 設定、`tool: api` はこの変更には含めない。
