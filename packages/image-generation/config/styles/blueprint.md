# 図解画像 スタイルプロンプト: Blueprint

**/image-gen の `--style blueprint` で適用されるスタイル定義。本文がそのまま画像生成指示に併用される。**

## ビジュアルスタイル: Blueprint / Architecture / Blue

### 配色

- 背景: #0047AB (Cobalt Blue) - 青写真の色。
- 主文字色: #FFFFFF (White)
- アクセントカラー: #87CEEB (Sky Blue)
- 配色はテーマの個性を伝えつつ、企業資料としての読みやすさと落ち着きを保つ

### タイポグラフィ

- 見出し: 製図文字（Architect's Daughter風）。
- 本文: 可読性を優先した本文書体
- スタイル: 全大文字, 規律正しい。
- 数値表現: 重要な数値は比較しやすく、情報の軸として見せる

### レイアウトグリッド

- 幾何学的で整然とした配置
- 余白を情報の品位と視認性を高める要素として扱う
- 単調になりすぎないよう、整列と余白の中に穏やかなリズムを持たせる
- 複数ページ一覧、コンタクトシート、サムネイルグリッドのような見せ方にはしない

### イラストスタイル

- 建築図面（ブループリント）の美学。
- 形状ルールは統一し、画面全体に一貫性を持たせる
- 質感やパターンは控えめに使い、主題を奪わない
- 平面図, 断面図, 寸法線。
- 図版はスタイルの個性を伝えつつ、主題の理解を支える役割に留める
- 企業資料として不適切な象徴性の強い意匠は避ける

### データビジュアライゼーション

- 表、図、要点を秩序立てて配置する
- 強調は必要最小限にし、読み取りの速さを優先する
- 図表はスタイルの個性を残しながらも、要点が素早く伝わる見せ方にする
- ラベル、見出し、数値は一目で関係が分かるように整える

### 含めるスライドタイプ

- タイトルスライド
  - 上部にタイトル、周辺に小さな補助情報、中央または右側に象徴ビジュアルを置いてよい
- 概要スライド
  - 左に大きな要点見出し、右に要約文や補足データを置いてよい
- 比較表スライド
  - 上部に比較テーマ、中央に比較表、下部に短い示唆を置いてよい
- データ整理スライド
  - 上段に主要数値、中段にチャート、下段に要点や注記を置いてよい
- フローまたは構造整理スライド
  - 左右または上下の流れで関係性を整理し、接続線や矢印は最小限に抑えてよい
- 出力時は各ページの内容に応じて上記のうち適切な1種類を選び、入力資料またはユーザーが指定した構成・枚数に沿って、必要な枚数のスライドを生成する

### トーン & ボイス

- 計画
- 設計
- 工業的
- 精密
- 知的
- 画面全体に節度ある存在感と洗練を持たせる
- 主題よりもスタイルが前に出すぎないようにする
- 目立ちすぎないが印象に残る見せ方を優先する
