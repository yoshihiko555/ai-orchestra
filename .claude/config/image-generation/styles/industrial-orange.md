# 図解画像 スタイルプロンプト: Industrial Orange

**/image-gen の `--style industrial-orange` で適用されるスタイル定義。本文がそのまま画像生成指示に併用される。**
技術記事の構成図・概念図向け。紺の設計図の上に白とスチールグレーの線画で描き、明るく赤みを抑えたオレンジを文字と細い線のアクセントにだけ使う。

## ビジュアルスタイル: Industrial / Blueprint / Orange

### 配色

- 背景: #002244 (Blueprint Blue)。
- 主文字色: #F5873A（明るく赤みを抑えたオレンジ）
- アクセントカラー: #FFFFFF (White)、#444444 (Steel Grey)

### 色の使い方

- オレンジは #F5873A 前後の、明るく赤みを抑えたオレンジ（朱色・赤・ネオンにしない）
- オレンジは見出しの文字、ラベルの文字、細い枠線、矢印の輪郭にだけ使う。大きな面をオレンジで塗りつぶさない
- 矢印やカードの中は、背景より少し明るい紺かスチールグレー。ラベルは塗りつぶした帯ではなく、背景の上にオレンジの文字で置く。説明の文は白
- 画面の大部分は紺の背景と白・グレーの線画。オレンジはアクセントとして全体の 1〜2 割程度にとどめる

### タイポグラフィ

- 見出し: モノスペース (例: DIN Mono, Roboto Mono)。
- スタイル: 技術的なラベル, スモールキャップス, 縦書きテキスト。

### レイアウトグリッド

- 厳格なグリッド, 密度の高い情報量, 整理されたカオス

- 工業的な安全色を差し色にした、技術的な回路図/設計図。
- 点線, 寸法線（矢印）, クロスヘア（照準）, グリッドオーバーレイ。
- ワイヤーフレームの3Dモデル, 機械の分解図。
